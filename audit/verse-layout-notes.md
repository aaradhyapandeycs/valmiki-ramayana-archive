# Verse line divisions

The layout collector uses explicit `<br>` and paragraph boundaries in the pinned primary Devanāgarī HTML. Spaces and newlines embedded in HTML text nodes do not start a visual line. Standalone closing bars and verse references stay with their preceding text. The reader adds display spans without changing the underlying Sanskrit or IAST text.
